# Proposal

## Why

On peut renommer un objet, mais pas le sac ni le départ qui le porte.

## What Changes

- Renommer un sac ne change ni le modèle ni les autres sacs.
- Renommer un modèle ne change pas les sacs.
- Renommer un départ ne change pas son modèle.
- Un nom vide ou déjà pris est refusé.
- L'agenda reprend le nouveau nom du sac, sans son contenu.
