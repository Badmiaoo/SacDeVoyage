# Proposal

## Why

Plusieurs gestes existaient à moitié : modifier un départ, modifier une action, copier les données, oublier Google, retirer un objet ajouté seulement dans un sac.

## What Changes

- Une action se modifie sans perdre sa coche.
- Les dates ou le jour d'un départ se modifient sans perdre les coches.
- Une copie JSON se télécharge et se reprend. Un fichier cassé est refusé.
- Oublier la connexion retire le jeton.
- Retirer un objet ajouté dans un seul sac ne le retire pas du modèle ni des autres sacs.
- À remplir, les affaires pas encore remises sont nommées.
